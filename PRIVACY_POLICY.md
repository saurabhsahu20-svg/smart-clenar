# S Cleaner — Privacy Policy

**Updated: 22 November 2026**

S Cleaner is a locally operating Android storage utility.

- **No accounts, advertisements or tracking.** We do not require users to sign in.
- **No personal data collected or uploaded by S Cleaner.** The app does not request Internet permission and does not transfer files to the developer.
- **Folder access is optional and user-initiated.** The Android system folder picker allows you to grant access only to a folder you choose, where Android permits it. S Cleaner stores the selected folder URI locally on your device to simplify future scans.
- **Local file analysis.** Junk file indicators, sizes and duplicate SHA-256 checks are computed on-device within the selected folder. File contents are read for hashes only; content is not retained or transmitted.
- **Deletion is user-controlled.** Files are never deleted from shared folders without your explicit selection and a confirmation dialog. Some deletions may be permanent.
- **App cache.** One-tap cleanup only deletes S Cleaner's own temporary cache. Cleaning other app caches requires using their official Android settings.
- **Storage usage.** Device storage statistics are read locally while the app is in the foreground; no background tracking service is installed.
- **Permissions.** No internet access, no unrestricted all-files permission, and no broad app-inventory permission. File access happens only through an Android-approved picker.
- **Data retention.** The selected folder preference remains on-device until app data is cleared or the app is uninstalled. You can revoke folder permissions using Android Settings.
- **Children.** The app is a general utility and does not collect personal information from children or adults.

Before publication, the app publisher should provide a public contact email and a hosted copy of this policy and keep the text accurate if future app behavior changes.
